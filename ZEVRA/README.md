# Pratiksha Kitchen Website

Premium responsive food-ordering website for Pratiksha Kitchen.

## Included
- Pratiksha Kitchen branding
- Responsive homepage
- Actual food image assets in `images/`
- Menu with prices and Add buttons
- WhatsApp, Call and Email contact actions
- Customer enquiry form
- Vercel API endpoint for Resend email delivery

## Deployment
Set these Vercel environment variables for email enquiries:
- `RESEND_API_KEY`
- `BUSINESS_EMAIL`
- `RESEND_FROM` (optional)

Update the phone/WhatsApp/email values in `js/script.js` before going live.
